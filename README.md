# Robotopia — Sosyal Medya Medya Deposu

Robotopia Kids Robotics & Coding Academy'nin sosyal medya görsel ve videoları.

Bu depo bir CDN görevi görüyor: Buffer API medyayı yalnızca **URL** olarak kabul ettiği
için, zamanlanan gönderilerin görselleri buradan servis ediliyor.

## Kullanım

Dosyalar `sm/` klasöründe. Doğrudan erişim adresi:

```
https://raw.githubusercontent.com/gorunmez/robotopia-medya/main/sm/<dosya-adi>
```

Örnek: https://raw.githubusercontent.com/gorunmez/robotopia-medya/main/sm/otto1.png

## İçerik

- `01`–`11` ile başlayanlar: kampanya kartları (Instagram 4:5, LinkedIn 16:9)
- `R01`, `R02`: Reels videoları (9:16)
- `otto1`, `aiasistan1`, `robotkol1`, `finalproject`: kur ürün fotoğrafları (Kur 1–4)
- `office1`, `office2`, `demoday1`: atölye ve Demo Day fotoğrafları
- `kesif-grubu`, `3dbaski`: ders anı fotoğrafları

## Not

Buradaki tüm görseller yayımlanmak üzere üretilmiştir. Depoda hiçbir kimlik
bilgisi, şifre veya kişisel veri bulunmaz.
